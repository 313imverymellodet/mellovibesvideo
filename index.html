Folder layout help
Inside the address above, make one folder per console, named exactly:
nes, snes, n64, segaMD, segaCD, dreamcast, psx, gba, arcade
Name each file as the game title in lowercase with dashes, for example
/nes/super-mario-bros.nes   /snes/chrono-trigger.sfc
The server must allow CORS (send Access-Control-Allow-Origin: *) on that folder.
